MAIN WINDOW: letter keys and the top-row 1-0 number keys now play the selected instrument.

    Z X C V B N M   (degrees 1-7)    A S D F G H J K L   (8-16)
    Q W E R T Y U I O P   (17-26)    1 2 3 4 5 6 7 8 9 0   (27-36)
- Pitch = instrument base x (1 + degree/12): equal-Hz steps, 12 per base interval. The instrument's base is the
  same one its PKP audition uses (Base Global Frequency x the instrument's Meum power). Steps/base is adjustable (1-48).
- Voice = the existing instrument audition voice on the polyphonic audition stream (chords work, oldest voice is stolen
  past the limit). Notes are 0.35 s; boost law is bypassed so the scale stays exact; frequency capped at 20 kHz.
- New "Key Chart" button (transport row 2): shows every key's degree, ratio and Hz for the selected instrument,
  has an on/off checkbox and the steps setting.
- Never steals typing: ignored while a text box / spin box / editable combo / item editor is the target, while a
  popup or dialog is open, for Ctrl/Alt/Meta combos, the numeric keypad, and held-key auto-repeat (one note per press).
  Only acts when the main window is the active window. Instrument dropdown no longer swallows letters.
