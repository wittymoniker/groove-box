Groovebox R28.4.50 HF28.1 — QTimer constructor-scope crash fix

Confirmed crash from the Run_hybrid HF28 log:
  UnboundLocalError: cannot access local variable 'QTimer' where it is not associated with a value
  at QTimer.singleShot(0, self._main_window_relaunch_filter.ensure_window_strip)

Root cause
  MathematiciansGrooveboxApp.__init__ imported QTimer inside a later try block.
  Python treats that name as local throughout the whole constructor, so the earlier
  HF28 QTimer.singleShot call failed before the UI was constructed.

Fix
  Use the already-present module-level PyQt6.QtCore.QTimer import; remove the
  constructor-local import and keep both early hardware-prime callbacks intact.
  Synchronized root groovebox.py and the active HF28 ISO app-overlay copy.
  Re-synchronized active ISO overlay performance.py with root source; the previous
  overlay copy was stale and failed the existing release-integrity check.
