This is a reconstruction release based on the latest complete source archive
available in the Library (R23r). It is NOT asserted to be the original R26 FULL3
build. R24-R26 source patches were not available in the recovered Library results.

Changes:
- Video render now writes to a suffix-preserving .part output, checks file size
  and positive duration, verifies an expected audio stream, then atomically
  replaces the destination. Failed render attempts remove partial output and
  preserve any existing destination.
- MP4-family renders request faststart metadata placement.
- Game-generated WAV assets are written to same-directory temporary files,
  reopened for validation, and atomically published to avoid half-written assets.
- Game asset installation logs individual generation errors instead of silently
  swallowing them, and processes Qt events during progress updates to keep the
  loading screen responsive.
- Root and ISO overlay video renderer sources are synchronized.

  missing historical R24-R26 patches were recovered.
