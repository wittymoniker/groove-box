# ISO Generated-Spec Dependency Repair

The supplied traceback identifies a missed source-verifier dependency:
`BUILD_ISO/verify_ram_root_io_20261031.py` tried to read
`build_executable/spec/MathematiciansGroovebox.spec`. That file is generated by an
EXE build, is excluded from the source archive, and must not be a prerequisite
for building the ISO. This exact dependency was not caught before the earlier
snapshots were shared.

## Repair

Seven packaging checks in that verifier now use `runtime_module_names()` from
the shared `runtime_payload.py`. BUILD_KIT uses that same function for its
hidden-import list. The verifier structurally checks that the builder consumes
the inventory and forwards each module to PyInstaller's hidden-import option.
It retains the feature/source/overlay checks rather than creating a dummy spec,
skipping missing files, or disabling verification.

The two unconditional spec reads are removed, along with all seven module-name
searches in the generated spec. Native catalog checks also receive an explicit
project working directory. No generated EXE spec or previous EXE build is needed.
