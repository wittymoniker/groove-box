BUILD STATUS / LIMITATION
A new hardware-ready ISO was not fabricated in this execution environment because grub-mkrescue/xorriso and Fedora package repositories are unavailable here. The existing small ISO was inspected and is not being relabeled as Latitude-hardware-ready because its initramfs does not contain the complete fat hardware/runtime stack. Build the supplied BUILD_ISO kit on Fedora with:

  sudo ./BUILD_LATITUDE_35X0_ISO.sh

Do not use --no-fetch for the appliance image. The builder now refuses hardware-ready output when the kernel/modules/runtime contract is incomplete.

FINAL CHECK
